`AirPodsIcon.qml` is an unchanged copy from
[Omapods](https://github.com/thisisgm/omarchy-pods/blob/fff7fec600a5b9a61cdb40e93eccbcceb4b8f824/AirPodsIcon.qml),

Its SHA-256 is `e0ca5e16d5b9213e1cc00c0baec2a0703187aff93646312f7ac034d541c6d603`.

The original component and fitting logic retain the
[Omapods MIT license](../icons/LICENSE.omapods). Apple's product outlines are
excluded from that license and from this project's GPL license; see the
[artwork notice](../icons/README.md). Inclusion does not grant rights to reuse
the outlines.

The QML is source material for `python3 scripts/import-omapods-icons.py`, run from
the project root. GNOME loads the generated SVGs, so the extension does not run
this QML component or require Omapods' desktop environment.
